## Inputs

- Official live API: [https://api.start-hack.5u.ai/docs](https://api.start-hack.5u.ai/docs)
- `.env.example` (`APP_MODE`, `LIVE_ACTIONS_ENABLED`, `DATABASE_URL`, keys)

## Outputs

- `GET /health/live`
- Mailbox poll + persist (`messages.external_id` unique)
- Router → RFQ job
- Gateway wrapper (no live spend in demo)
- Worker claim loop on `jobs`
- Outbox / `action_intents` delivery status
- `alembic upgrade head` on api start

## What the scaffold already implements

- `core/config.py`: `APP_MODE`, `live_allowed()`, database URL
- `core/errors.py`: `LiveActionsDisabled`, `NotFoundError`, `ConflictError`
- `contracts/models.py`: Message, RFQ, RateCandidate, QuoteDecision, ActionIntent, Booking, Session, SessionEvent, money strings
- `contracts/adapters.py` + `external.py`: live DTO names and protocol methods
- `db/models.py` + `repositories.py`: tables, job claim, cursor, upsert message
